# Vision

## Confirmed requirements

- A playful, polished, modern portfolio experienced as a vertical journey through the sky.
- The user owns creative direction and architecture; discuss significant choices before implementation.
- Explore stylized 3D, soft motion, depth, and interaction. The requested aesthetic is **not anime**.
- Keep portfolio content in readable HTML. Use 3D primarily for environment and objects.
- Support desktop/mobile, touch/keyboard, reduced motion, and sensible performance.
- Build through small, testable milestones. Placeholders are never implicit design approval.
- Use placeholder professional content until the user provides real details.

## Initial concept, not finalized

Three hot air balloons represent experiences. Each could support independent placement, gentle idle motion, hover, activation, focus transitions, readable details, and a clear way back to the scene. Both the representation and interaction are open to iteration.

Environmental possibilities include clouds at different depths, birds, airplanes, floating islands, and other whimsical objects. This is an idea list, not an asset requirement or authorization to build them all.

## Recommendations to explore

- Use a single scene canvas, keeping the HTML journey readable if it fails.
- Prototype one object's interaction before applying it to all three experiences.
- Compare visual references in Figma; consider Spline only when its modeling/export workflow solves a specific need.

## Undecided

Final palette, typography, lighting/materials, object silhouette, composition, motion timing, camera path, scroll depth, mobile scene density, final content, and hosting. Camera zoom, modal, and side panel are all open options.

## Milestone 1 boundary

Build the application and documentation foundation, a sky gradient, a viewport-sized scene section, native vertical scroll, and simple objects. No final art direction, detailed assets, elaborate motion, or full portfolio content.
