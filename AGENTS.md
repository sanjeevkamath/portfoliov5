# Interactive Sky Portfolio

Read `README.md` for the current Figma studies and project status.

The user is the creative director. Work on one bounded part of the design at a time. Share the change for review before moving to a new creative decision. The current scope is the landing page with sculpted cloud lettering and an Explore action. Work in Figma. Start the replacement website only when the user requests implementation.

Keep the visual work original and use licensed assets. Record photo credits and source links. As motion is designed, consider keyboard and touch access and a reduced-motion alternative. Preserve real user-provided content and avoid invented portfolio copy.
